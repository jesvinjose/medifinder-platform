# medifinder-platform
🚀 A full-stack platform to help users find affordable generic medicines, connect with nearby medical stores, and consult doctors — built with Node.js, TypeScript, MongoDB, and Next.js.

MediFinder is a tech-driven platform focused on making healthcare more accessible and affordable. It enables:

🔎 Users to search for generic and branded medicines, find substitutes, and locate nearby pharmacies with stock.

🏥 Medical Stores to list available medicines and manage inventory.

👨‍⚕️ Doctors to register and offer consultations to users.

🏢 Pharmaceutical Companies to list their products for bulk purchases.

The platform is built using Node.js + TypeScript (Backend), MongoDB (Database), and Next.js (Frontend) with a focus on SEO, scalability, and mobile-first UX.
